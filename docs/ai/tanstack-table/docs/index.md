# TanStack Table docs

> Supercharge your tables or build a datagrid from scratch in any framework while retaining 100% control over markup and styles.

- [Docs index](https://tanstack.com/table/latest/docs/index.md): This same Markdown index.
- [LLMs index](https://tanstack.com/table/latest/llms.txt): This same Markdown index.
- [Library home](https://tanstack.com/table/latest)
- [GitHub](https://github.com/tanstack/table)
- Packages: @tanstack/table-core, react-table.
- Frameworks: Angular, Ember, React, Preact, Solid, Svelte, Vue, Qwik, Lit, Alpine, Vanilla.

Use this index as the routing layer for the docs. Fetch one linked Markdown page at a time, and prefer framework-specific pages when the user names a framework.
